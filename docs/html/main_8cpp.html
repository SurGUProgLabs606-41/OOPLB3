Detailed Description

Лабораторная работа №3, вариант №7.

Программа демонстрирует классы Date и Event, конструкторы, деструктор, перегрузку операторов, explicit, mutable, статическое поле и обработку исключений.

Выполненные задания:

  1. Три конструктора.
  2. Префиксные и постфиксные ++ и –.
  3. Операторы +=, -=, *=, /=.
  4. Бинарные арифметические операторы и сравнения.
  5. Использование explicit и mutable.
  6. Одно статическое поле.
  7. Пользовательский деструктор.
  8. Демонстрация операторов в main().
  9. Демонстрация запрета неявного преобразования.
  10. Изменение mutable-поля константного объекта.

Returns
0 при успешном выполнении; 1 при обработанном исключении.

[Задание 1] Демонстрация трёх конструкторов.

d1 создаётся конструктором по умолчанию, d2 — параметризованным конструктором, d3 — конструктором копирования.

[Задания 5 и 9] Демонстрация explicit.

Date d4(15) разрешено: конструктор вызывается явно. Date d5 = 15 запрещено, поскольку explicit блокирует неявное преобразование int в Date.

[Задание 2] Демонстрация ++ и –.

Префиксная форма возвращает изменённую дату, постфиксная — копию даты до изменения.

[Задание 3] Демонстрация +=, -=, *= и /=.

[Задание 4] Демонстрация бинарных арифметических операторов.

Операторы +, -, * и / возвращают результат. Исходный объект c не изменяется.

[Задание 4] Демонстрация операторов сравнения.

[Задания 5 и 10] Демонстрация mutable у const-объекта.

constDate нельзя изменять обычными операциями. Однако print(), getDay(), getMonth() и getYear() увеличивают accessCount, потому что поле объявлено mutable.

Создаёт список мероприятий и выводит расписание.

Каждый Event содержит название и объект Date.

Подсчитывает мероприятия за октябрь и за весь 2026 год.

[Задание 6] Выводит количество существующих объектов Date.

Учитываются объекты, которые существуют в этой точке программы, включая поля date объектов Event.
